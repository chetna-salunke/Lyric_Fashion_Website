# Lyric Fashion

<img width="2040" height="2329" alt="lyric-website-preview" src="https://github.com/user-attachments/assets/84a83614-809a-4151-887a-13ce69028b88" />

React + Vite fashion store. Animated home page, shop, product pages, categories/collections, about, support, bag + wishlist, checkout and validated forms.

## Why I Built This

I wanted to build a fashion website where I could work on both the design and development side of the project.

Before starting the development, I first created the website design in Figma. After finalizing the design, I converted the design into a working React.js website.

This project helped me practice creating reusable components, responsive layouts, navigation, product sections, and a clean use r interface.

## Design

The initial design and layout were created in **Figma** before development.

The goal was to keep the design simple, modern, and easy to use while making sure it works well across different screen sizes.
